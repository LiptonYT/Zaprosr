☠ КАРАТЕЛИ | КРАСИВОЕ ОФОРМЛЕНИЕ БОТА

Обновлённый бот запросов ролей для Discord.

Что изменилось:
- Чёрно-бордовая концепция и стилизованные цветные Embed-карточки.
- Красивая публичная панель с пошаговой инструкцией.
- Оформленная карточка заявки для старшего состава.
- Цветные решения: одобрение — зелёное, отказ — красное, доработка — золотое.
- Дата/время, номер заявки, иконка сервера и подпись KARATELI.
- Более приятные уведомления и кнопка «Подать заявку».

Что сохранено:
- /role_setup и /role_publish.
- Выдача нескольких ролей сразу и смена ника.
- Заявки в один указанный канал, без создания новых каналов.
- Отклонённые заявки и доработки НЕ отправляются в кадровый аудит.
- Ограничение на повторные заявки и восстановление кнопок после перезапуска.

Установка:
1. Остановите процесс Bothost.
2. Замените bot.py, не удаляя .env и SQLite-файл.
3. Выполните: pip install -r requirements.txt
4. Запуск: python -u bot.py
5. Используйте /role_publish для публикации новой красивой панели.
6. Старую публичную панель при необходимости удалите вручную.

Дайте боту разрешения Manage Roles, Manage Nicknames, Send Messages, Embed Links.
Его роль должна находиться выше всех выдаваемых ролей.
