КАРАТЕЛИ | ЗАПРОС РОЛИ — версия без выбора подразделения
========================================================

В этой версии НЕТ списка и выбора подразделений.
Пользователь нажимает одну кнопку «Запросить роль» и заполняет:
- имя и фамилию;
- кто он: новичок / действующий участник / возвращается;
- дополнительную информацию (необязательно).

После отправки создаётся приватный канал заявки. Старший состав нажимает:
- Одобрить;
- Отклонить;
- На доработку.

При одобрении бот выдаёт ОДНУ заранее настроенную роль и меняет никнейм
на формат [Подпись] Имя Фамилия. Роль и подпись задаются администратором
в настройках бота. По умолчанию можно указать «Учеб Отдел».

Установка:
1. Python 3.11+.
2. pip install -r requirements.txt
3. Скопировать .env.example в .env и вставить BOT_TOKEN.
4. Запустить python bot.py.

Настройка:
1. В Developer Portal включить Server Members Intent.
2. Пригласить бота со scopes bot и applications.commands.
3. Выдать права: View Channels, Send Messages, Embed Links, Read Message History,
   Manage Channels, Manage Roles, Manage Nicknames.
4. Роль бота поставить выше целевой роли.
5. Выполнить /role_setup и нажать «Настроить бота».
6. Указать ID:
   - канала, где будет панель;
   - категории приватных заявок;
   - роли старшего состава;
   - одной роли, которую бот выдаёт после одобрения;
   - канала аудита (необязательно).
7. В поле «Подпись в никнейме» написать, например, Учеб Отдел.
8. Выполнить /role_publish.

Команды:
- /role_setup — настройки.
- /role_publish — опубликовать панель.

Это отдельный бот только для запроса одной настроенной роли. Проверяйте на тестовом сервере.
