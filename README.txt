КАРАТЕЛИ — ЗАЯВКИ В ОДИН КАНАЛ

Команды: /role_setup, /role_publish.

ВАЖНО: В /role_setup укажите отдельно:
1. ID канала с кнопкой «Запросить роль» (panel_channel_id).
2. ID обычного ТЕКСТОВОГО канала для поступления заявок (applications_channel_id).
3. ID роли проверяющих.
4. Несколько ID выдаваемых ролей, через запятую.
5. Подпись никнейма.

Через «Настроить аудит» установите отдельно канал логов.
Все заявки появляются сообщениями в одном указанном канале с кнопками
Одобрить / Отклонить / На доработку. Новые тикет-каналы НЕ создаются.
Пользователь увидит подтверждение после отправки заявки.

ОБНОВЛЕНИЕ BOTHOST:
- Остановите бота, замените bot.py.
- Сохраните существующие .env и karateli_roles.sqlite3.
- Запустите python -u bot.py.
- ВЫПОЛНИТЕ /role_setup ПОВТОРНО: старый ID категории не используется,
  новый ID текстового канала для поступления заявок обязателен.
- Не нужно перепубликовывать старую панель, кнопка будет работать после перезапуска.
- Старые созданные каналы бот автоматически не удаляет: удалите их вручную,
  если в них не осталось нужных заявок.

Бот должен видеть указанный канал и иметь право отправлять сообщения,
встраивать ссылки (Embed Links), читать историю; назначать роли и менять никнеймы.
Его роль должна стоять выше выдаваемых.
