КАРАТЕЛИ | ЗАПРОС РОЛИ — НЕСКОЛЬКО РОЛЕЙ + БЫСТРЫЙ ОТКЛИК
================================================================

Команды: /role_setup и /role_publish.

Что изменилось:
- В настройках роли можно задать 1–20 Discord ID через запятую.
- После одобрения все роли выдаются одним запросом к Discord.
- Никакого выбора подразделения участником.
- Подпись никнейма задаётся отдельно, например «Учеб Отдел».
- Бот сразу подтверждает взаимодействие, чтобы кнопки не зависали,
  а затем выполняет действие и обновляет заявку.
- Приватные заявки с кнопками сохраняют работоспособность после перезапуска.
- Результат отправляется в ЛС и отдельно в настроенный канал аудита.
- Старые настройки target_role_id автоматически используются до сохранения нового списка.
- Сохраняется прежняя SQLite-база karateli_roles.sqlite3.

Запуск Bothost:
1. Остановите бота.
2. Замените только bot.py; существующие .env и базу данных не удаляйте.
3. Установите зависимости: pip install -r requirements.txt
4. Команда запуска: python -u bot.py
5. В Discord: /role_setup → «Настроить бота».
6. В поле «ID ролей» вставьте через запятую, например:
   123456789012345678,234567890123456789,345678901234567890
7. Укажите подпись, например: Учеб Отдел
8. Настройте отдельной кнопкой ID канала аудита.
9. Используйте /role_publish, чтобы разместить панель в указанном канале.

Бот должен иметь права Manage Roles, Manage Nicknames, Manage Channels, Send Messages,
Embed Links, View Channel, Read Message History и включённый Server Members Intent.
Роль бота обязана быть выше всех назначаемых ролей.
Discord всё равно ограничивает скорость своих API-запросов; мгновенное завершение
сети гарантировать нельзя, но взаимодействия подтверждаются сразу.

ВНИМАНИЕ: пробуйте одобрение на тестовом сервере.
